# iMirror for macOS

iMirror mirrors and controls an Android phone or tablet from your Mac over USB or Wi-Fi.

## Download

Download the latest `iMirror-*-macos-universal*.dmg` file from the [GitHub Releases page](https://github.com/ErIMRANALAM/iMirror-Releases/releases/latest).

The universal app supports Apple silicon and Intel Macs running macOS 14 or later. Android Platform-Tools are downloaded from Google after you accept Google's SDK terms if ADB is not already installed.

Visit the [iMirror website](https://erimranalam.github.io/iMirror-Releases/) for the product overview, manual, pricing, terms and privacy policy.

See [INSTALL.md](INSTALL.md) for setup and connection instructions. Review the release notes and signature status on each release before installing.

## Updates

From version 0.2.0 on, iMirror updates itself: it checks this repository's `appcast.xml` once a day (or choose **iMirror › Check for Updates…**) and installs signed, verified updates. Version 0.1.6 has no updater: install 0.2.0 once from the Releases page.

## Privacy

Device communication stays between your Mac and the Android device over USB or your local network. Screen captures are saved only to the location you choose. See the [iMirror privacy policy](https://erimranalam.github.io/iMirror-Releases/privacy/).
