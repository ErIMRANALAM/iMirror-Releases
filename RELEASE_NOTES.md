# iMirror 0.2.0

Universal macOS release for Apple silicon and Intel Macs running macOS 14 or later.

## What's new

- **Licence.** iMirror is free to try for 14 days with every feature. After that, **iMirror Lifetime** is a one-time $9 licence for one person, active on one Mac at a time, with every future update. Enter a key under iMirror › Licence… (⇧⌘L).
- **In-app updates.** iMirror checks for new versions once a day (switch it off in Help & About), and iMirror › Check for Updates… checks at once. Updates are signed and verified before they install.
- Help & About shows your version, licence and update status; the user manual covers both.

Updating from 0.1.6: version 0.1.6 has no updater, so download this release once and drag `iMirror.app` over the old one.

## Install

Download `iMirror-0.2.0-macos-universal.dmg`, open it, and drag `iMirror.app` to Applications. See [INSTALL.md](https://github.com/ErIMRANALAM/iMirror-Releases/blob/main/INSTALL.md) for Android USB and Wi-Fi setup.

This app is signed with the OAW INFOTECH LLP Developer ID and notarized by Apple. The stapled notarization ticket has been verified.
