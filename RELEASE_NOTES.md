# iMirror 0.1.6

Universal macOS release for Apple silicon and Intel Macs running macOS 14 or later.

## Install

Download `iMirror-0.1.6-macos-universal-release.dmg`, open it, and drag `iMirror.app` to Applications. See [INSTALL.md](https://github.com/ErIMRANALAM/iMirror-Releases/blob/main/INSTALL.md) for Android USB and Wi-Fi setup.

This app is signed with the OAW INFOTECH LLP Developer ID and notarized by Apple. The stapled notarization ticket has been verified.
